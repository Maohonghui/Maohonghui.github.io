<%*
/*
 * 博客文章模板（Templater）
 * ────────────────────────────────────────────────────────────────────────
 * 需要的 Obsidian 插件：Templater（你的仓库里已经装了）
 *
 * 用之前先确认两件事：
 *   1. 设置 → Templater → Template folder location 指向这个「模板」文件夹
 *   2. 设置 → 文件与链接 → 新附件的默认存放路径 建议设为 assets/img/posts
 *
 * 用法：新建笔记 → 插入模板 → 选「博客文章模板」
 * 日期会自动填好；title / categories / tags / description 留给你手动写，
 * 留空也不会有问题（不会导致构建失败，见仓库 _plugins 里的说明）。
 */
const pad = (n) => String(n).padStart(2, '0');
const now = new Date();
const ymd = `${now.getFullYear()}-${pad(now.getMonth() + 1)}-${pad(now.getDate())}`;
const hms = `${pad(now.getHours())}${pad(now.getMinutes())}${pad(now.getSeconds())}`;

/* 标题默认值：优先用文件名里日期后面的部分（也就是文章的网址 slug）。
   文件名是 2026-10-08-181224      → 标题 181224
   文件名是 2026-10-08-我的第一篇   → 标题 我的第一篇
   所以建议新建笔记时就把文件名起好，文章网址会好看很多。 */
const base = tp.file.title || '';
const m = base.match(/^\d{4}-\d{2}-\d{2}-(.+)$/);
const titleDefault = (m && m[1]) ? m[1] : hms;
_%>
---
# ── 自动填写 ────────────────────────────────────────────────
title: "<% titleDefault %>"                    # ← 改成你的标题，它同时也是网址
date: <% tp.date.now("YYYY-MM-DD HH:mm:ss") %> +0800

# ── 请手动填写（留空也可以，但建议留空时就把整行删掉或写成 ""）──
categories:
  -                        # ← 分类，写一个词，例如：随笔 / 学习 / 折腾
tags:
  -                        # ← 标签，可以写多个
description: ""            # ← 文章卡片和搜索结果里显示的小字

# ── 封面图 ──────────────────────────────────────────────────
# 插入封面：把图片拖进笔记，再到下面 path 里填 /assets/img/posts/文件名.jpg
# 不要封面就保持现在的写法（path: "" 是安全的，不会产生裂图）
image:
  path: ""
  # alt: "封面说明"

# ── 一般保持默认 ────────────────────────────────────────────
pin: false                 # 置顶
toc: true                  # 右侧目录
comments: true             # 评论区
math: false                # 数学公式

# ⚠️ media_subpath 必须留空！
# 它会被主题拼在图片路径前面。而下面 image.path 已经是以 / 开头的绝对路径，
# 一旦这里填了 /assets/img/posts，实际路径就会变成
#   /assets/img/posts/assets/img/posts/xxx.jpg
# 从而 404 裂图。留空即可，正文里的绝对路径本来就能正常工作。
media_subpath: ""

# ── GitHub Publisher 需要（删掉会导致 no pb set in frontmatter 报错）──
pb-publish: true
pb-type: post
---
