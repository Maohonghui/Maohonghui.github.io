你好，我是 Tony。这里是我的个人博客，用来存放笔记、想法和一些折腾记录。

## 这个站点

- 使用 [Jekyll](https://jekyllrb.com) + [Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy) 主题
- 部署在 GitHub Pages，每次推送自动构建
- 文章大多是在手机上的 Obsidian 里写的，通过 GitHub Publisher 发布过来
- 评论区基于 GitHub Discussions（Giscus），用 GitHub 账号登录即可留言

## 都在写什么

主要是学习笔记和日常记录。分类和标签在左侧栏可以翻。
